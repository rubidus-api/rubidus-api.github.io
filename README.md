# rubidus-api.github.io

The landing page at <https://rubidus-api.github.io/>: one static `index.html`
introducing each public project, with its repository, its release page, and a
direct download of the newest build.

The page is generated and self-contained — styles are inlined, and it loads no
script, font, or stylesheet from anywhere else. English and Korean text sit in
two columns side by side, stacking on a narrow screen.

Errors and broken links are welcome as issues.
